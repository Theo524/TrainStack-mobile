# TrainStack

TrainStack is a mobile workout planning and training app built with Expo and React Native.

## Current features

- Workout planner
- Workout suggestions
- Today screen with daily date
- Daily motivational quote
- Train screen
- Stopwatch
- Custom rest timer
- Exercise checklist
- Finish workout flow
- Stats and workout history
- Edit, delete, and duplicate planned workouts
- Exercise library
- Custom exercises
- Workout templates
- Settings screen
- Phone storage with AsyncStorage
